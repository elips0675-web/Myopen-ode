Таблица
Критерий	Балл	Что изменилось
Архитектура и код	9/10	Разделение на agent.py + tools.py + rag.py + ui.py — чисто. 22 инструмента, subagents, plugins, MCP, LSP — это уже архитектура уровня коммерческого продукта. Минус: run_agent_loop всё ещё монолитен, но теперь с суммаризацией каждые 3 итерации.
Функциональность	9.5/10	22 инструмента против 14 ранее. Добавлены: LSP, subagents, skills, patch, todo, question, websearch, multi-project, session sharing, plugins, slash-команды, DeepSeek-V4-Flash. Это уже функциональный паритет с OpenCode Desktop по core-фичам.
Безопасность	8.5/10	Directory traversal protection, bash sandbox (чёрный список), retry с backoff — отлично. Но всё ещё нет sandbox для bash (команды выполняются от имени пользователя, просто фильтруются). Нет rate limiting, нет auth.
UX/UI	8/10	Подсветка синтаксиса, confirm-диалоги, drag-and-drop, tab completion, progress bar, тёмная тема, mobile-responsive — существенный прогресс. Но всё ещё inline-HTML без npm, что ограничивает возможности редактора (нет Monaco/CodeMirror).
Потенциал	9.5/10	С LSP, MCP, plugins и 1M контекстом — это уже не pet-project, а платформа. Один шаг до полноценного open-source конкурента OpenCode/Cursor в нише local-first.
Что впечатляет в новой версии
LSP интеграция — goToDefinition, findReferences, hover, documentSymbol. Это то, чего нет у 90% open-source агентов. Вы поднялись на уровень IDE.
Subagents с разными правами — @explore (read-only), @scout (web), @general (full). Это прямо как в OpenCode — и это работает через отдельные system prompt.
Skills система — .agent_skills/*.md — переиспользуемые инструкции. Killer feature для повторяемых workflow (например, «как деплоить на Vercel»).
Patch tool — unified diff вместо полной перезаписи. Это критично для больших файлов.
Bash sandbox + directory traversal — реакция на ревью. Показывает зрелость подхода.
Multi-project — переключение между проектами с отдельными сессиями/RAG. Это уже workspace management.
DeepSeek-V4-Flash — поддержка 1M контекста. С этим можно отказаться от RAG для маленьких проектов и скармливать код целиком.
MCP сервер — интеграция с VS Code/Cursor/Claude Desktop. Это дверь в экосистему.
Что всё ещё можно улучшить (приоритетно)
Таблица
Приоритет	Что	Почему важно
🔴 Высокий	Native Monaco editor в UI	Сейчас просмотр файлов — это <pre>. Для редактирования кода нужен Monaco или CodeMirror. Это единственное серьёзное отставание от OpenCode.
🔴 Высокий	Streaming tool execution	Сейчас агент ждёт полного ответа, потом парсит тулзы. OpenCode stream-ит токены и тут же исполняет тулзы — UX быстрее.
🟡 Средний	SQLite вместо JSON для сессий	При 100+ сессиях JSON на диске станет bottleneck. SQLite + FTS для поиска по истории.
🟡 Средний	Git diff в UI	Сейчас diff — текстовый вывод. Нужен структурный diff с подсветкой +/- как в GitHub.
🟡 Средний	Autocomplete в чате	@ для упоминания файлов, / для slash-команд, # для skills — как в OpenCode.
🟢 Низкий	Tauri/Desktop	pywebview — ок, но Tauri даст нативное окно с лучшей производительностью.
