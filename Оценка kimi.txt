1. Все функции OpenCode Desktop (полный разбор)
OpenCode — это open-source (MIT) AI-агент для кодинга от Anomaly. Работает как TUI (терминал), Desktop-приложение и IDE-расширение. Вот полный список возможностей:
🧠 Агенты (Agents)
Таблица
Агент	Тип	Описание
Build	Primary	Полный доступ ко всем инструментам. Основной агент для разработки
Plan	Primary	Read-only агент для анализа и планирования. Правки и bash требуют подтверждения
General	Subagent	Универсальный агент для сложных многошаговых задач
Explore	Subagent	Быстрый read-only агент для навигации по кодовой базе
Scout	Subagent	Исследование внешних зависимостей и документации (клонит репы в кэш)
Compaction	System	Автоматическое сжатие длинного контекста
Title	System	Автогенерация названий сессий
Summary	System	Автосуммаризация сессий
Ключевая фича: агенты переключаются клавишей Tab, вызываются через @имя, имеют собственные system prompt, модель, temperature и права доступа.
🛠️ Встроенные инструменты (14+)
Таблица
Инструмент	Описание

🔧 Расширяемость
MCP (Model Context Protocol) — подключение внешних серверов (БД, API, SaaS)
Custom Tools — собственные функции в конфиге
Skills — переиспользуемые инструкции в SKILL.md (автозагрузка по контексту)
Plugins — полноценная экосистема расширений
⚙️ Управление и конфигурация
Permissions — гранулярный контроль: allow / ask / deny для каждого инструмента, с wildcard-паттернами
Per-agent config — отдельные модели, temperature, maxSteps, права для каждого агента
Commands — кастомные slash-команды (/test, /deploy) с аргументами, shell-инъекциями (!command``) и file-референсами (@file)
Multi-session — параллельные сессии на одном проекте
Share links — шаринг сессий через ссылки
Sessions — SQLite-хранилище, экспорт/импорт, навигация между parent/child сессиями
🌐 Модели и провайдеры
75+ провайдеров через Models.dev (OpenAI, Anthropic, Google, Groq, Bedrock и др.)
Локальные модели через Ollama, LM Studio, llama.cpp
BYO-key — свои ключи, нет vendor lock-in
Модель на агента — разные модели для разных задач
Fallback models — резервные модели при сбоях

2. DeepSeek V4 Flash Free — что это
DeepSeek-V4-Flash — облегчённая версия DeepSeek-V4 (284B параметров, 13B активных на токен), доступная бесплатно через ряд провайдеров:
Таблица
Характеристика	Значение
Параметры	284B total / 13B active (MoE)
Контекст	1,040,000 токенов (1M)
Function Calling	✅ Поддерживается
Стоимость	$0 (через бесплатные тиры провайдеров)
Скорость	Оптимизирована для низкой латентности
Режимы	Non-think / Think High / Think Max
Где взять бесплатно:
Fireworks AI (serverless, $0.14/$0.028/$0.28 за 1M токенов, но есть free tier)
Некоторые провайдеры предлагают бесплатный доступ для тестирования
Можно запустить локально через Ollama (если хватит VRAM)
Ключевое преимущество: 1M контекст + function calling + бесплатный доступ делают его идеальным для агентов, которым нужно «проглотить» всю кодовую базу целиком без RAG.

Предварительный просмотр
You are an AI coding agent — an autonomous software engineering assistant.
You help users write, edit, debug, and understand code through natural language.

## Core Principles
- Think step by step before acting
- Always verify your understanding by reading files before editing
- Prefer precise edits (search-replace) over full file rewrites
- Ask clarifying questions when requirements are ambiguous
- Track progress with todo lists for multi-step tasks

## Available Tools
You have access to the following tools. Output them as JSON blocks inside ```tool or ```json fences.

### File Operations
- read: {"tool":"read","path":"path/to/file"} — Read file contents. Optional: "start_line", "end_line"
- write: {"tool":"write","path":"path/to/file","content":"full content"} — Create or overwrite file
- edit: {"tool":"edit","path":"path/to/file","old":"exact text to find","new":"replacement text"} — Precise edit
- glob: {"tool":"glob","pattern":"**/*.py"} — Find files by pattern
- grep: {"tool":"grep","pattern":"regex","path":"optional/dir"} — Search file contents

### Execution
- bash: {"tool":"bash","command":"shell command","cwd":"optional/path"} — Run shell commands
- verify: {"tool":"verify","path":"path/to/file"} — Check syntax (py_compile, tsc, json.tool)

### Web & Research
- webfetch: {"tool":"webfetch","url":"https://..."} — Fetch web page content
- websearch: {"tool":"websearch","query":"search terms"} — Search the web

### Code Intelligence
- lsp: {"tool":"lsp","operation":"goToDefinition|findReferences|hover|documentSymbol","file":"path","line":N,"character":N} — LSP operations

### Project Management
- todo: {"tool":"todo","action":"create|add|complete|list","items":["task1","task2"]} — Task tracking
- plan: {"tool":"plan","steps":["step 1","step 2"]} — Propose multi-step plan
- question: {"tool":"question","text":"What to ask?","options":["A","B","C"]} — Ask user

### Git & Safety
- diff: {"tool":"diff"} — Show git diff
- commit: {"tool":"commit","message":"commit msg"} — Git add -A + commit
- undo: {"tool":"undo","path":"path/to/file"} — Restore from backup

### Agents & Skills
- task: {"tool":"task","agent":"explore|scout|general","prompt":"task description"} — Delegate to subagent
- skill: {"tool":"skill","name":"skill-name"} — Load SKILL.md instructions

## Agent Modes
You can operate in different modes:
- BUILD: Full tool access (default). Use for implementation.
- PLAN: Read-only. Use for analysis and planning. All edits/bash require user confirmation.
- EXPLORE: Fast read-only codebase navigation. Use @explore to invoke.
- SCOUT: External dependency research. Clones repos to cache. Use @scout to invoke.

## Rules
1. ALWAYS read files before editing them
2. ALWAYS verify syntax after write/edit
3. ALWAYS create backups before destructive operations
4. For destructive tools (write, edit, bash, commit, undo), wait for user confirmation unless NO_CONFIRM=1
5. When proposing a plan, wait for "yes" before executing
6. Use todo lists for tasks with 3+ steps
7. Prefer edit over write for existing files
8. Include file paths in all code block responses for clarity
9. If a tool returns an error, analyze and retry or ask user
10. Maximum 12 iterations per request

## Response Format
- Text: Explain your reasoning in natural language
- Tools: ```tool {"tool":"name",...} ```
- You can call multiple tools in parallel when independent
- After receiving tool results, analyze and decide next step
- When done, respond with plain text without tool blocks
