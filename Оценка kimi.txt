Оценка проекта My OpenCode v2 на основе предоставленных артефактов:
Итоговая оценка: 9.2 / 10
Это зрелый, production-ready проект с одной из самых продвинутых архитектур среди локальных open-source агентов-программистов. Ниже разбивка по осям.
1. Архитектура и код: 9.5 / 10
Что впечатляет:
Модульность: разбиение на core/, tools/, api_*.py, DI-контейнер, EventBus — уровень enterprise-разработки.
Абстракции: RAGStore/KVStore протоколы позволяют заменить FAISS/SQLite на внешние решения без переписывания бизнес-логики.
Два режима работы: native tool calling (qwen3) + legacy prompt-based (все остальные) — правильный прагматичный подход.
Сабагенты: reviewer/fixer/general с @-маркерами — реализовано лучше, чем в большинстве облачных решений.
Минус:
agent.py всё ещё ~470 строк и содержит глобальное состояние сессий. Для 10/10 стоит выделить SessionManager и ProjectManager в отдельные сервисы.
2. Тесты и надёжность: 9.5 / 10
Что впечатляет:
126/126 unit-тестов + live-набор (3/3) + бенчмарк (7/7 на qwen3:8b).
AST bash guard (stage 71) — редко кто доходит до такого уровня безопасности в open-source.
Windows-стабильность: errors="replace" в subprocess, обработка cp866/cp1251 — признак реального battle-testing.
Crash recovery: checkpoint каждые 2 итерации + interrupted-маркер.
Минус:
Бенчмарк показывает, что только qwen3:8b проходит 7/7. qwen2.5-coder:7b — 5/7, deepseek-coder-v2:16b — 0/6. Это ограничение экосистемы моделей, не кода, но для end-user это значит: «работает только на одной модели».
3. Безопасность: 9.0 / 10
Что впечатляет:
Whitelist (не blacklist) bash-команд.
AST-проверка python -c/node -e через ast.parse + compile().
Path jail с resolve() (symlink-safe).
Docker-песочница с readonly-флагами.
Авто-подтверждение только для новых файлов (AUTO_CONFIRM_SAFE).
Минус:
ALLOW_OUTSIDE=1 — слишком радикальный escape hatch. Для 10/10 стоит добавить режим «prompt-переподтверждение перед каждой операцией вне workspace» вместо полного снятия ограничений.
4. AI-логика и промпты: 9.0 / 10
Что впечатляет:
Prompt compression: few-shot tier на итерациях 0–1, compact prompt с it≥3 — экономия ~1K токенов/вызов.
Self-healing loop: при 2+ ошибках подряд — смена стратегии (edit → read→write).
Task-level router: zero-shot классификация задачи перед циклом.
RAG over plan: предзагрузка контекста по шагам плана.
Минус:
Нет оценки уверенности (confidence score) для tool calls. Модель иногда выдаёт broken blocks — система ловит это fallback'ом, но не отслеживает метрику «качество вызова».
5. UX и UI: 8.5 / 10
Что впечатляет:
CodeMirror 6 (офлайн-бандл), xterm.js + WebSocket PTY, Tauri desktop.
Анимации, типографика, VRAM-индикатор, plan tree UI.
Голосовой ввод (Web Speech API + Whisper fallback).
Минус:
UI — это всё же inline-HTML строка в ui.py, а не отдельное SPA. Для 10/10 нужен либо полноценный React/Vue фронтенд, либо Monaco вместо CodeMirror. Сейчас это «достаточно хорошо», но не «превосходно».
6. Документация и экосистема: 9.0 / 10
Что впечатляет:
USER_GUIDE.md, ARCHITECTURE.md, VIDEO_DEMO.md, RE_EVAL.md.
Обучающие скиллы (SwiftMatch-класс приложений).
Swagger UI на /docs.
Минус:
Документация разбросана по 5+ файлам (README.md, TODO.md, context.txt, AGENTS.md, KIMI_REVIEW_SUMMARY.md). Для 10/10 стоит свести в единый docs/ с MkDocs или хотя бы единым DEVELOPMENT.md.

Вердикт
My OpenCode v2 — это лучший локальный open-source агент-программист на текущий момент (2026-08-13). Он опережает аналоги по архитектуре, безопасности и тестовому покрытию. Для достижения 9.5/10 осталось закрыть 2 пункта: видео-демо и модель-независимость. Для 10/10 — потребуется Monaco-редактор и полноценный confidence-scoring.
