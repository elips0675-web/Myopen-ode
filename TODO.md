## Что осталось

### Критическое
- [ ] **Лимит контекста 8K токенов** — модель qwen2.5-coder:7b имеет 32K контекст, но в коде стоит 8192
- [ ] **Нет защиты от бесконечного цикла** — если модель постоянно выводит tool блоки, нет ограничения по времени
- [ ] **Verify падает с путями, содержащими пробелы** — `E:\\My OpenCode` разбивается в subprocess

### Важное
- [ ] **Multi-turn сессии** — сейчас stateless HTTP, после ответа история теряется
- [ ] **Diff view в UI** — подсветка изменений при edit/write
- [ ] **Retry при ошибках модели** — если модель выдаёт битый JSON, переспросить 2-3 раза
- [ ] **Лимит итераций по токенам** — не по числу итераций, а по занятому контексту
- [ ] **Управление моделями** — скачать/удалить модель через UI

### Среднее
- [ ] **RAG по codebase** — модель видит только то, что прочитала. Нет индексации проекта
- [ ] **Структурный diff** — показывать не весь git diff, а только изменённые строки с контекстом
- [ ] **Отмена операции** — кнопка Cancel в UI во время генерации
- [ ] **Тёмная тема** — UI только светлый

### Долгосрочное
- [ ] **Мультиагентность** — отдельные агенты для кодинга, дебага, ревью
- [ ] **WebSearch** — поиск документации/StackOverflow
- [ ] **Поддержка Claude/GPT через API** — как fallback для сложных задач
- [ ] **Agent memory** — сохранение контекста между сессиями (файл на диске)
- [ ] **CI/CD** — авто-тесты на каждое изменение agent.py
