plain
@skill architect

2. Ключевые модули и их связи (нарисуй текстовую диаграмму)
3. Схема БД — все таблицы и связи
4. API endpoints (группировка по доменам: auth, profile, social, premium...)
5. WebSocket события и их payload

7. Security patterns (JWT flow, rate limiting, CORS, upload validation)

Используй: glob, grep, read, list. Не пиши код — только анализ.
