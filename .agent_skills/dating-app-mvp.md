# Dating App MVP - оффлайн-приложение знакомств (skill)

Use this skill when the task is to BUILD a complete offline dating app MVP as
3 static files in E:\swiftmatchmy1 (drop a task file in that exact folder in
the user's request, or the word "знакомства"/"dating app"/"свайпы").

## ЦЕЛЬ
Создать в папке `E:\swiftmatchmy1` РОВНО 3 файла — index.html, styles.css,
app.js — полностью работающее оффлайн-приложение для знакомств на русском
языке. Работает от простого открытия index.html в браузере (file://). Все
данные — localStorage. Без сборки, без npm, без сервера, без внешних API.

## ЖЁСТКИЕ ПРАВИЛА (нарушение = провал)
1. ЕДИНСТВЕННАЯ рабочая папка — E:\swiftmatchmy1. НИКОГДА не открывай, не

2. НЕ запускай bash вообще: никаких npm, pip, git, установок, команд.

3. НЕ останавливайся, пока не готовы ВСЕ 3 файла. Не пиши «абосс значит так

4. В конце обязательно вызови verify по всем трём файлам и исправь через edit
   любые найденные ошибки. Только после этого напиши итоговое сообщение с
   перечнем файлов и их размеров.

## ФУНКЦИИ (все обязательны)
- Вход: экран с полями «Имя» и «Возраст», кнопка «Начать»; сохранение в
  localStorage; после входа — показ карточек.
- 10 анкет-заглушек в локальном массиве PROFILES: имя, возраст, эмодзи-аватар
  (🧑💼 👩🎨 🧑🚀 👨🍳 👩⚕️ 🧑🔬 👩🎓 🤠 🧑🏭 👩🌾), короткая биография,
  теги интересов (#кофе #путешествия #музыка ...).
- Свайпы: карточка анкеты с кнопками «лайк»/«дизлайк»; drag-перетаскивание
  мышью/пальцем с наклоном; анимация ухода карточки (влево/вправо), штампы
  «LIKE»/«NOPE» поверх карточки.
- Взаимные симпатии: из 10 анкет примерно 5-6 «лайкают в ответ» (массив
  LIKES_BACK). Если пользователь лайкнул анкету из LIKES_BACK — попадает в
  раздел «Совпадения».
- Чат с совпавшими: список совпадений, открытие чата с выбранной анкетой,
  история сообщений в localStorage, сообщение = текст + время, после
  сообщения пользователя анкета отвечает через ~1 сек одной фразой из
  AUTO_REPLIES (массив).
- «Мой профиль»: редактирование имени/возраста/о себе, кнопка «Сбросить» —
  полный сброс localStorage и возврат к экрану входа.
- Нижняя навигация: Карточки ♥ / Совпадения 💬 / Профиль 👤.

## ДИЗАЙН
Мобильный стиль Tinder (max-width ~430px, по центру экрана). Тёмная тема:
фон тёмно-фиолетовый градиент (например #14121f → #1b1630), карточки
#221e33, акцентный градиент розово-фиолетовый (#ff4d88 → #7c5cff). Скругления
~18px, мягкие тени. Плавные переходы. Аватар — крупный эмодзи в круге.

## СТРУКТУРА ФАЙЛОВ
- index.html: `<script src="app.js" defer></script>`, экраны: login, cards
  (стек карточек + кнопки), matches (список + чат), profile; нижняя навигация;
  ротация экранов CSS-классом .active / .hidden.
- styles.css: все стили по разделу ДИЗАЙН.
- app.js: константы PROFILES/LIKES_BACK/AUTO_REPLIES, state в localStorage
  (ключ условный, например "dating_mvp_v1"), функции: renderDeck, like/
  dislike, initDrag (pointer events), addMatch, renderMatches, openChat,
  addMessage, autoReply, renderProfile, saveProfile, resetAll, init (проверка
  входа). Весь DOM — по id/классам из index.html, без конфликтов имён.
