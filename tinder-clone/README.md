## Tinder Clone Web App

A swipe-based dating app with date notices and matching functionality. Built with React, Node.js, and Firebase.

### Features
- User profiles with photo swiping
- Real-time match notifications
- Chat functionality
- Dating statistics dashboard

### Setup
1. Clone the repo: `git clone https://github.com/your-username/tinder-clone.git`
2. Install dependencies: `npm install`
3. Run the app: `npm start`
