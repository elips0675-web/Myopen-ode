1. UI и UX
Нет подсветки синтаксиса в просмотре файлов и диффах — читать код сложно.

Нет встроенного редактора — только просмотр, править можно только через чат.

Файловое дерево не обновляется автоматически после записи/удаления файлов (только по кнопке).

Мобильная версия не адаптирована — боковая панель на узких экранах перекрывает контент.

2. Производительность и масштабирование
Индексация RAG выполняется при каждом запуске заново — для больших проектов (тысячи файлов) это долго. Нет кеширования эмбеддингов на диск.

Суммаризация контекста срабатывает только по числу символов, а не по токенам — для DeepSeek-R1 с его 32K это не критично, но можно точнее.

Нет прогресс-бара для длительных операций (pull модели, индексация).

3. Безопасность и стабильность
Bash-команды выполняются без sandbox — потенциальная уязвимость, если пользователь не внимателен (даже с подтверждением).

Нет ограничений на чтение вне WORK_DIR — можно прочитать любой файл на диске (абсолютные пути разрешены), что не всегда желательно.

Обработка ошибок местами примитивная — при падении Ollama агент просто молчит, нет повторных попыток с экспоненциальной задержкой.

Таймаут 60 секунд жёсткий — для сложных планов или больших файлов может не хватить, лучше сделать настраиваемым.

4. Функциональность
Структурный дифф — сейчас показывает весь файл, а хотелось бы только изменённые строки с контекстом.

Нет поддержки отладки (debugger) или выполнения кода с интерактивным вводом.

Нет автодополнения (tab completion) в чате для путей и команд.

Память (agent_memory) сохраняет только последние 10 сессий, а не все, и не позволяет искать по ним.

5. Архитектура
agent.py слишком толстый (~900 строк) — хорошо бы вынести agent loop, сессии, контекст-менеджмент в отдельные модули.

Нет юнит-тестов для каждого инструмента (только 11 smoke-тестов) — сложно рефакторить.

Зависимости — только requests, fastapi, uvicorn, но для работы с TypeScript/JSON проверок нужны внешние утилиты (tsc, python), которые могут отсутствовать в системе.

6. Документация
README на русском — хорошо, но нет английской версии для международного сообщества.

Нет примера использования (видео или скриншотов), хотя UI уже есть.

Не описаны все переменные окружения (например, DEBUG, AGENT_MAX_ITER, AGENT_TIMEOUT).

Если резюмировать: самые критичные доработки — это улучшение UI (подсветка, редактор), кеширование RAG и безопасность bash. Остальное — приятные бонусы, которые поднимут оценку с 8.3 до 9+.
