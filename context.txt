PURPOSE
-------
Local AI coding assistant that replaces cloud-based tools (like DeepSeek Cursor).
Runs entirely offline on RTX 3060, powered by Ollama + qwen2.5-coder:7b.
User types a task in browser, model calls tools to read, edit, write, run code.

KEY ACHIEVEMENT
---------------
Model (qwen2.5-coder:7b) does NOT natively support tool_calls in Ollama.
BUT we engineered a prompt-based agent loop: model outputs ```tool blocks,
backend parses them, executes, feeds result back. This works and is verified.

ARCHITECTURE
------------
agent.py (~380 lines) — single file, zero pip dependencies beyond fastapi+uvicorn.

1. FastAPI server on port 8765
2. HTML UI served at GET / (inline, no npm)
3. POST /api/chat — SSE streaming endpoint
4. Agent loop: up to 12 iterations of model -> tool -> result -> model
5. File versioning: backups in .agent_backups before every write/edit
6. Verify step: py_compile for .py, tsc --noEmit for .ts, json.tool for .json
7. Git integration: diff + auto-commit

TOOLS (10 total)
----------------
read    — read file content
write   — write new file (with backup + verify)
edit    — replace oldString with newString in file (with backup)
bash    — run shell command
glob    — find files by pattern
grep    — search file contents
list    — list directory
diff    — git diff (changes since last commit)
commit  — git add -A + git commit
undo    — restore previous backup of a file
verify  — syntax check a file

HOW AGENT LOOP WORKS
--------------------
1. System prompt instructs model to output ```tool blocks
2. Model responds with explanation + ```tool {"tool":"read","path":"..."}
3. Backend parses JSON, executes tool, appends result as user message
4. Model sees result and continues (reads, edits, verifies, commits)
5. Loop ends when model responds without a tool block

Example flow: model reads file -> edits -> verifies -> commits, all autonomously.

MODEL USED
----------
qwen2.5-coder:7b (quantized, running on RTX 3060 12GB via Ollama)
Also available: qwen2.5-coder:1.5b, qwen2.5-coder:3b, deepseek-r1:7b, qwen3:8b
