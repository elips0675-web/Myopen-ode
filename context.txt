PURPOSE
-------
Local AI coding assistant that replaces cloud-based tools.
Runs entirely offline on RTX 3060, powered by Ollama + DeepSeek/qwen models.
User types a task in browser, model calls tools to read, edit, write, run code.

KEY ACHIEVEMENT
---------------
- Prompt-based tool calling: qwen2.5-coder:7b/DeepSeek does NOT support native tool_calls in Ollama.
  Engineered a working agent loop: model outputs ```tool blocks, backend parses, executes, feeds back.
- Sessions: full session management with save/load to .agent_sessions/*.json
- RAG: semantic code search via Ollama embeddings with cosine similarity
- Self-hosted, zero-cost, fully offline alternative to Cursor/Claude Code

ARCHITECTURE
------------
agent.py (~900 lines) — single file, zero npm deps, only fastapi+uvicorn+requests.

1. FastAPI server on port 8765
2. HTML UI served at GET / (inline, no npm, no build tools)
3. POST /api/chat — SSE streaming endpoint with session support
4. Agent loop: up to 12 iterations, 60s timeout, 3 JSON retries, auto-execute fallback
5. File versioning: backups in .agent_backups before every write/edit (up to 50 versions)
6. Verify step: py_compile for .py, tsc --noEmit for .ts/.js, json.tool for .json
7. Git integration: diff + auto-commit
8. Context management: auto-summarization via 1.5b model when >4K chars
9. RAG: semantic code search via Ollama embeddings (nomic-embed-text)
10. Sessions: full CRUD for chat sessions (create, list, load, delete)

TOOLS (14 total)
----------------
read    — file content (absolute/relative paths + http/https URLs)
write   — create file anywhere (with backup + verify)
edit    — replace text in file (with backup)
bash    — run shell command (with cwd support)
glob    — find files by pattern (any directory)
grep    — search file contents (with cwd support)
list    — list directory (any path)
web     — fetch URL content
diff    — git diff
commit  — git add -A + git commit
undo    — restore previous backup
verify  — syntax check a file
plan    — propose multi-step plan, user confirms
search  — RAG semantic code search

SAFETY
------
- Confirmation before write/edit/bash/commit/undo (with UI buttons)
- Plan tool: model proposes steps, user confirms before execution
- Backups in .agent_backups/ (up to 50 versions)
- Timeout: 60s total, 3 retries on JSON parse errors
- 32K context window (maximized from 8K)
- NO_CONFIRM=1 skips all confirmations
- JSON Schema validation for all 14 tools

HOW AGENT LOOP WORKS
--------------------
1. System prompt tells model it has tools and must output ```tool blocks
2. Model responds: text + ```tool {"tool":"read","path":"file.py"}
3. Backend parses JSON, validates schema, executes tool, appends result as user message
4. Model gets result, decides next step (read more, edit, verify, commit)
5. Loop ends when model responds without a tool block
6. Fallback: if user says "yes"/"да" and no tool block found, auto-executes pending tool

MODELS

RAG: nomic-embed-text
